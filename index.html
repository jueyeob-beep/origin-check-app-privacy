origin.check 앱 개인정보처리방침

시행일: 2026년 11월 6일 · 운영 주체: 부안마케팅영농조합법인(인스타그램 origin.check) · 운영 대행: 주식회사 향유

1. 이 앱은 무엇인가

origin.check 앱은 부안마케팅영농조합법인이 운영하는 Meta(페이스북 · 인스타그램) 광고 계정과 페이지 · 인스타그램 계정의 운영 성과를 집계하고 광고 예산을 조정하기 위한 내부용 도구입니다. 일반 이용자에게 제공되는 서비스가 아니며, 페이스북 로그인 등 외부 이용자의 계정 연동 기능이 없습니다.

2. 수집 · 이용하는 정보

  • Meta Marketing API를 통해 받는 광고 계정의 집계 성과 데이터(광고비, 노출, 클릭, 랜딩페이지 조회 등)와 캠페인 · 광고 세트 · 광고의 설정값(이름, 예산, 상태, 타겟 조건)
  • Meta Graph API를 통해 받는 자사 페이지 · 인스타그램 계정의 집계 인사이트(조회, 도달, 팔로우, 프로필 방문 등)

이 앱은 개별 이용자(광고를 본 사람, 팔로워, 댓글 작성자 등)의 이름 · 연락처 · 프로필 같은 개인을 식별할 수 있는 정보를 수집하지 않습니다. 위 데이터는 모두 Meta가 제공하는 집계 수치입니다.

3. 이용 목적

  • 일간 · 주간 · 월간 운영 보고서 작성
  • 광고 성과에 따른 예산 배분 · 캠페인 켜고 끄기 등 광고 운영

4. 보관과 보호

수집한 집계 데이터는 운영 대행사(주식회사 향유)의 업무용 컴퓨터와 비공개 저장소에 보관하며, 보고서 작성과 광고 운영 외의 목적으로 쓰지 않습니다. API 접근 토큰은 암호화된 비밀값으로만 보관하고 외부에 공개하지 않습니다. 보관 기간은 대행 계약 기간 동안이며, 계약 종료 시 삭제합니다.

5. 제3자 제공

수집한 데이터를 제3자에게 판매하거나 제공하지 않습니다. 보고서는 부안마케팅영농조합법인에만 전달합니다.

6. 데이터 삭제 요청

이 앱에는 외부 이용자 데이터가 없습니다. 자사 계정 관련 데이터의 삭제나 앱 연결 해제를 원하시면 아래 연락처로 요청해 주세요. 요청 접수 후 7일 안에 처리하고 결과를 알려드립니다.
